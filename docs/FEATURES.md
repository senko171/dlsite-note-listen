# 完整功能与规则

## 自动更新提醒

与优惠助手 dlsite-best-deal 同一套机制，用户无需手动 reinstall：

- 脚本每 6 小时检查一次最新版本；成功才记时间，失败下次打开页面再试。
- 版本源两个：GitHub API `releases/latest` 和 jsDelivr `resolved`，取两者中较大的版本号，避免单一源缓存到旧版造成误判或漏报。
- 发现新版时右下角出现一条提示条：`有新版本 vX.Y.Z（当前 vX.Y.Z）`，附「去更新」链接和关闭按钮。点「去更新」打开钉死版本的安装链接；点关闭后记住该版本，不再重复提示，出了更新的版本才会再提示。
- `备注`弹窗 → `备份 / 恢复`区有「检查更新」按钮，可随时手动检查，会明确反馈「已是最新版本」或直接弹提示。
- 与脚本管理器自带的「检查更新」互不冲突：后者走 `@updateURL` 的 `releases/latest/download/...` 永久地址自动升级。
- 版本比较按 `.` 拆分逐段比较数字（去掉开头 `v`），如 `0.0.10` > `0.0.9`、`1.0.0` > `0.9.9`。

## 双键的含义

- `备注`：点开输入框写任意文字，保存后按钮上直接显示内容（过长自动省略号）。已写备注时按钮为浅蓝底；再点可修改。
- `试听`：点击在 `未试听` / `已试听` 之间切换，已试听为浅粉底。取消后恢复未试听。

两条状态属于同一份记录，以最后保存的时间为准。备注弹窗左下角显示这条记录最后一次保存的本地时间（精确到分钟）。

## 按键出现的位置

| 页面 | 位置 | 规则 |
| --- | --- | --- |
| 作品详情 | 购买区兄弟节点 | 排在优惠券插件 UI（史低卡 / 优惠券框 / 比较语言版本按钮）之后，绝不进入原生按键容器 |
| 搜索 / 分类 / 推荐卡 | 标签区之后 | 与优惠券插件同一行，桌面两键并排；窄屏 / 触屏一键一行 |
| 收藏夹 / 稍后再买 | 卡片标签区之后 | 与列表页一致 |
| 购物车 | `cart_list_item_inner` 之后 | 不改动购物车原生结构 |

不出现：`排行`板块（含整页排行）、评论区。避免信息密度过高时干扰原页面。

## 数据规则

- 存储位置：浏览器 `localStorage`，键 `dlwb-note-listen-v1`；只存本机，不联网上传。
- 数据项：每条作品记录含 `note`（备注文字）、`listened`（是否试听）、`updatedAt`（最后保存时间）。
- 家庭（语言版本）映射：同一作品的原作 / 翻译版 / 子作品归到同一个 key，备注与试听共享。
- 冲突解决：按 `updatedAt` 较新者胜出；时间相同时保留已有记录。主动清空备注 / 取消试听能生效，不会被旧备份复活。
- 家族识别来源：详情页 `data-language-editions` 属性（零请求）优先；否则请求公开接口 `/maniax/product/info/ajax`（不带 Cookie），每批 10 个 id；失败写 7 天负缓存。
- 多标签页同步：监听 `storage` 事件，一处改动其它页立即刷新。

## 备份 / 恢复

- 入口：任意备注弹窗里的 `备份 / 恢复`，或脚本管理器菜单（支持 `GM_registerMenuCommand` 时）。
- 导出：`.json` 文件，文件名形如 `dlsite-note-listen-2026-11-21.json`，包含备注数据、家庭映射和导出时间。
- 恢复：选文件后按记录时间合并，只覆盖更旧的记录；兼容早期的 `DLWB1:` 备份码与 `.txt` 文件。
- 换设备流程：旧设备导出 → 传文件到新设备 → 安装脚本 → 从文件恢复。

## 安全边界

- 不读取账号、优惠券、购物车、已购清单；公开作品信息请求不带登录 Cookie。
- 不自动购买、加购物车、套券、切换语言。
- 不访问第三方 AI / 翻译服务。
- 所有状态以本机为准，清理浏览器数据会丢失，请定期备份。
